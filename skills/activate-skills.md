## Instructions for skills usage for AI:

- When updating/creating/refactoring/deleting any code in bounds of the project context, please read the skill folder `shared-conventions-skill` and then proceed.

- When updating/creating/refactoring/deleting any code in bounds of the `server` folder or some other side folder regarding a service or server of the application please read skill folder `server-side-skill` and then proceed.

- When updating/creating/refactoring/deleting any code in bounds of the `client` folder please read the skill folder `client-side-skill` and then proceed.
